# Release Notes: v0.2.0

**Release Date:** 2026-09-13

## Highlights

v0.2.0 adds change analysis and container/sandbox topology to the SAS model, and
renames the Go module to match the renamed repository:

- **Semantic diff engine** — a typed `ChangeSet` between two architectures, with
  change-impact classification.
- **Baseline / Assessment / ChangeReview model** — structured review of an
  architecture change against a baseline.
- **FedRAMP change-assessment profile** — three-outcome change classification
  with control-mapping hooks and decision-support language.
- **Container & sandbox topology** — new `compute.container` / `compute.sandbox`
  node kinds and `container` / `sandbox` boundary kinds for K8s-native and
  sandboxed-execution modeling; the Threat Model Spec bridge now emits
  `sandbox` / `container` / `breached` instead of collapsing to `network`.
- **Module rename** — `github.com/plexusone/systems-architecture-spec` →
  `github.com/plexusone/systemspec-architecture`.

## What's New

### Semantic Diff and Change Review

A new `diff` package computes a typed `ChangeSet` between two `Architecture`
models, classifies the impact of each change, and produces a
`Baseline`/`Assessment`/`ChangeReview` structure for reviewing an architecture
change against a baseline.

### FedRAMP Change-Assessment Profile

`diff/fedramp` provides a three-outcome change classification (with
control-mapping hooks and decision-support language) aimed at FedRAMP
significant-change assessments.

### Container & Sandbox Kinds

- Node kinds: `compute.container` (an OCI container or Kubernetes Pod) and
  `compute.sandbox` (a CaaS/code-interpreter sandbox or microVM).
- Boundary kinds: `container` and `sandbox`.
- `bridge/threatmodel.boundaryType()` now emits `sandbox` / `container` /
  `breached` rather than collapsing these to `network`.

See [`SPEC.md`](../spec.md) §2.1 and §4 for the updated kind taxonomies.

### Module Rename

The Go module and repository were renamed to
`github.com/plexusone/systemspec-architecture`. Update imports accordingly:

```go
import "github.com/plexusone/systemspec-architecture/sas"
```
